# 西班牙＋地中海家族任務遊戲

2026/12/8–2027/1/6 全家七人的旅行遊戲：每天解鎖城市卡、到景點打開景點卡、答題、玩小遊戲、拍九宮格上傳。

這裡放**腳本**和**遊戲網站**。網站上線步驟請看 `設定教學.md`。每次修改後重新上傳，GitHub 會自動保留每一個版本，隨時可以回頭看以前寫了什麼。

在 GitHub 網頁上點任何一個 `.md` 檔，就會直接顯示成排好版的文章，不用安裝任何東西。

## 怎麼看以前的版本

1. 點進任何一個檔案。
2. 按右上角的「History」（時鐘圖示）。
3. 每一筆就是一個版本，點進去可以看到那一版的全文，以及跟上一版差在哪裡（紅色是刪掉的、綠色是新加的）。
