# 西班牙＋地中海家族任務腳本

Oct 13, 2026 · @ss

## 怎麼用這份腳本

玩法分兩層：城市卡每天早上解鎖一張，景點卡到了哪個景點就打開哪一張。所有閱讀都可以按「跳過，直接答題」，不愛讀的家人照樣能玩。

1. **城市卡（每天一張）**：一個台灣人很少聽過的小故事、這座城市和大家熟悉的世界史怎麼串起來、今天吃什麼買什麼（它的歷史、八卦、經典搭配）、當地習俗、「今日九宮格」2–3 個拍照主題（這座城市街上很常見的東西，家人各選不同主題，拍滿 9 張一鍵拼貼、一鍵上傳）、「台灣連結」，最後 3 題加分題。
2. **景點卡**：西班牙的城市不綁日期，點進城市就看得到所有可能去的景點，想去哪個就開哪個。每張卡是 3–5 則 fun facts 加一段故事 → 出發前 5 題（4 題短題＋1 題長題）→ 景點小遊戲（西班牙的景點才有，種類見下表）→ 現場任務 → 收尾 3 題。
3. **題目考的是意義，不是年代**：問它代表什麼時代、象徵什麼、為什麼重要。每題答完會跳出「解說」，把它放回當時的社會：誰出錢、誰反對、哪些階級在衝突、為什麼它會在那個年代出現。不讀故事的人也能從解說學到東西。
4. **兩種難度**：選「初階版」只答標【初階】的題；選「我要挑戰」全部都答，【挑戰】題分數加倍。
5. **現場驗證題**：要到現場找答案並拍照證明，給不愛讀書的人最好的得分機會。

計分建議：初階題 10 分、挑戰題 20 分、長題 30 分、現場驗證 20 分、現場任務 30 分、城市卡加分題每題 15 分，每晚全家投票的「今日最佳照片」加 30 分。

## 遊戲種類

西班牙的每張景點卡都配一個小遊戲，同一座城市盡量不重複。郵輪週不配遊戲。

| 遊戲 | 怎麼玩 | 計分 |
| --- | --- | --- |
| 連連看 | 網頁列出一組照片或名字和一組意義（例如國王與他做過的事），用手指配對 | 配對一組 5 分 |
| 命運之輪 | 到景點轉一次輪盤，轉到什麼就做什麼：模仿一個雕像、學一句當地話、找一個顏色… | 完成 20 分 |
| 神秘任務 | 實體籤抽出的秘密任務，只有自己看得到，被發現就作廢 | 完成 30 分 |
| 物價猜猜猜 | 看一樣當地商品先不看標價，全家在一分鐘內各自輸入猜價 | 最接近 20 分 |
| 步數猜猜猜 | 進景點前猜「這裡逛完會走幾步」，出來對答案 | 最接近 20 分 |
| 小小觀察家 | 數一數、找一找：例如「這面牆上有幾隻獅子」，第一個答對的人拿分 | 最快 20 分 |
| 特寫尋寶 | 網頁先給 3 張局部特寫，找到實物並拍「它＋自己」合照 | 每張 20 分 |
| 當一次雕像 | 挑一幅畫或一尊雕像，全家照著擺姿勢，每晚投票最像的 | 投票第一 30 分 |
| 一句當地話 | 學一句西班牙文或加泰隆尼亞文，對店員說出來並錄下來 | 完成 15 分 |

## 技術決定

網頁放在 GitHub Pages，上傳照片和共用資料交給 Google Apps Script，兩個都免費。只用其中一個都會少一塊。

| 工作 | 放哪裡 | 原因 |
| --- | --- | --- |
| 遊戲畫面、題目、fun facts、九宮格拼貼 | GitHub Pages | 載入快、可以離線、可以加入主畫面。Apps Script 的網頁包在 Google 的框架裡，不能離線，頂端還會有 Google 的提示橫幅 |
| 一鍵上傳到共享雲端硬碟 | Apps Script | GitHub Pages 是靜態網頁，寫不進 Drive，除非每個家人都登入 Google 授權。Apps Script 用你的帳號寫入，家人不用登入 |
| 全家動態牆、分數、投票 | Apps Script＋Google 試算表 | 同一支程式順便記一筆，網頁從表裡讀 |

**原圖上傳**：你有付費的共享雲端硬碟，就不壓縮。照片一張一張傳，每張手機照片約 3–8MB，在 Apps Script 的單次上傳限制內。影片太大，先不支援。

**強制用瀏覽器開啟**：兩層保險。

1. 貼到 LINE 群組的連結後面加上 `?openExternalBrowser=1`，LINE 會直接用 Safari 或 Chrome 打開。
2. 網頁自己偵測，如果還是在 LINE 或其他 App 裡打開，整個畫面只顯示一個大按鈕「用瀏覽器開啟」，不讓人繼續玩。

「加入主畫面」沒辦法強制，建議出發前一晚全家一起裝好。裝過的手機，暫存的照片比較不會被清掉。

**網路**：題目、fun facts、拍照和拼貼都能離線，只有上傳和動態牆要網路。郵輪上的 Wi-Fi 通常要另外買，建議在靠港時用手機網路上傳。突尼斯不在歐盟漫遊範圍，當天的照片會先存在手機，回到船上或下一個港口再傳。網頁可以加一個「只在 Wi-Fi 上傳」的開關。

**大家看得到彼此的拼貼和分數嗎？** 可以，這套設定就是為此而設計的：

1. **上傳什麼**：拼貼在手機上做好後，一次送出 9 張原圖和 1 張拼好的九宮格，存進共享雲端硬碟「日期／城市／主題」資料夾。
2. **記分數**：每次上傳或答題，Apps Script 就在試算表寫一列：誰、哪天、哪張卡、得幾分、圖片檔。分數由試算表依人、依天自動加總。
3. **看動態牆和排行**：網頁打開時、下拉重新整理時，或每 60 秒自動向 Apps Script 要最新資料。不是即時推播，家人的新拼貼大約一分鐘內會出現。
4. **離線時**：答題和拍照先存在手機，連上網再補送。每筆都帶唯一編號，重送也不會重複加分。
5. **家庭密碼**：Apps Script 設成「任何人都能呼叫」家人才不用登入，所以網頁加一組只有家人知道的密碼，避免外人亂傳。

要注意一個限制：網頁要顯示雲端硬碟裡的圖片，檔案要允許「知道連結的人可以檢視」。共享雲端硬碟的這個權限是 Google Workspace 管理員設定的，若被關掉，就改由 Apps Script 回傳縮圖給網頁。出發前我們先測一次。七個人一天幾百次上傳，遠低於 Apps Script 的每日用量上限。
